### 🛡️ Capsule

[**Capsule**](https://shrimpworks.github.io/capsule-corp/) is a local-first experiment in running JavaScript jobs proposed by AI agents without giving the agent open-ended access to the host.

A person reviews and authorizes an immutable plan, then the job runs in a disposable, isolated guest with only the authority it was given. Capsule is under active development and should not be treated as a production security boundary.

[View the source on GitHub](https://github.com/Shrimpworks/capsule-corp)
